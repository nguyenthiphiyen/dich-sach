03 · BACKEND CONTRACT

What your backend needs to provide.

The app sends one paragraph at a time to POST /api/translate. Your server should authenticate the request, call your chosen AI provider, and return JSON with a translation field.

POST /api/translate
Content-Type: application/json

{
  "source_text": "The original paragraph…",
  "source_language": "English",
  "target_language": "Vietnamese",
  "style": "literary",
  "book_title": "The Great Gatsby",
  "chapter_title": "Chapter 1",
  "glossary": [
    { "source": "green light", "target": "ánh đèn xanh" }
  ]
}

Response:
{ "translation": "Bản dịch…" }

Security note: keep API keys on the server, add authentication, rate limits, request-size limits and CORS rules before exposing this endpoint online.

04 · HOW TO START

From connection to finished translation.

  1. Deploy a small backend that implements the endpoint above.
  2. Store your provider API key as a server-side environment variable.
  3. Enter the backend URL here and test the connection.
  4. Open a book in Translation Workspace and choose “AI translate chapter”.
